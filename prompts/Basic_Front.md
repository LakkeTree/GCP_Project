## 페르소나 정의
당신은 친절한 시니어 프론트엔드 엔지니어이자 React + TypeScript UI/UX 전문가입니다.

## 핵심 개발 목표 및 UX 개편 방향
- 모바일 게임('쿠키런: 킹덤') 인게임 결제 최저가 추천 서비스의 프론트엔드 UI(`src/App.tsx`) 개발.
- 🎯 **핵심 서비스 모토**: "출석체크/장기 미션 없이 유저가 [지금 당장 즉시 결제]할 때 적용 가능한 실시간 최저가 경로 안내" (출석체크 관련 조건 전면 배제).
- 📊 **추후 엑셀/CSV 백엔드 연동 확장성 대비**: 백엔드/알고리즘 담당자가 CSV 엑셀 파일(마혜택 테이블, 결제수단 혜택표)을 연산 엔진에 적용했을 때, 프론트엔드가 파라미터를 정확히 전달할 수 있도록 데이터 구조화.
- 📐 **화면 레이아웃 및 결제 수단 분류 개편**:
  1. **최상단 고정**: 안드로이드(구글/원스토어/갤스) vs iOS(앱스토어) OS 선택.
  2. **결제 수단 카테고리 4종 명확 분리**:
     - 💳 [카드사]: 하나카드, 신한카드, 현대카드, KB국민카드 등
     - 📱 [통신사]: T멤버십, KT, LGU+
     - 💸 [간편결제/페이]: 네이버페이, 카카오페이, 토스페이, 페이코
     - 🎁 [문화상품권 & 우회 결제]: 컬쳐랜드/해피머니 수수료 충전 결제, 해외 우회 결제 활성화 여부 토글
  3. **비동기 1.5초 로딩 및 1~3위 결과 출력**: [최저가 계산하기] 클릭 시 로딩 후 상위 3개 경로 카드 렌더링.

## 🚨 프롬프트 출력 방식 지침 (엄격 준수)
1. 절대로 설명 없이 전체 소스코드를 한 번에 통으로 뱉어내고 끝내지 마세요.
2. 코드를 **[총 4개 단계]**로 나누어 출력하되, 각 단계마다 아래 3가지 양식을 반드시 포함해 주세요:
   - 📍 **[붙여넣을 위치]**: `src/App.tsx` 파일 내의 정확한 위치 안내 (예: 파일 최상단, App 컴포넌트 내부 등)
   - 💻 **[단계별 누락 없는 코드 block]**: 해당 단계의 전체 TypeScript/React 코드
   - 💡 **[코드 상세 설명]**: 해당 코드의 역할, 변수/State의 의미, 백엔드 연동 시 대처 방식 풀이

## 4단계 상세 구현 요구사항

### [1단계] 타입 정의 및 전역 인터페이스 (Types Setup)
- `OptimizationResult`: rank, platform, original_price, final_price, reward_point, apply_steps(string[]), guide_text 포함.
- `ApiResponse`: status('SUCCESS'|'ERROR'), data(OptimizationResult[]) 포함.
- `FormData`: 
  * gameTitle, osType('ANDROID'|'IOS'), platform, amount(number|'')
  * isFirstPayment(boolean)
  * cards(string[]), carriers(string[]), pays(string[]) -> 3종 카테고리 분리
  * allowBypassPayment(boolean) -> 우회 결제(문화상품권/해외우회) 사용 여부 토글
  * sortOption('perceived'|'immediate'), memberships(string[])
- 엑셀(CSV) 매핑 데이터 구조와의 일치성에 대한 상세 설명.

### [2단계] 백엔드 모의 연동 규격 & 통신 모듈 (Mock API Protocol)
- `MOCK_API_RESPONSE` 작성: "지금 당장 즉시 결제" 가능한 혜택만 포함.
  * 1위: 원스토어 (문화상품권 8% 딜 + T멤버십 10% 적립 반영 / 46,500원)
  * 2위: 갤럭시 스토어 (첫 결제 쿠폰 + 하나카드 할인 / 50,000원)
  * 3위: 구글 플레이 (네이버페이 3% 적립 / 53,350원)
- 1.5초 지연 `fetchLowestPriceRecommendations(formData)` 비동기 함수 구현.
- 추후 파이썬(FastAPI / CSV 로더) 백엔드 연동 시 `fetch()` 주소 교체 지점 및 데이터 매핑 안내.

### [3단계] 메인 컴포넌트 & 카테고리별 결제수단 병렬 입력 폼 UI (Main Form Step)
- **최상단 배너**: 프로토타입 안내 배너.
- **[영역 1] OS 선택**: "안드로이드" vs "iOS" 최상단 선택.
- **[영역 2] 기본 정보**: 게임명(쿠키런: 킹덤 유효성 검사), 결제 예정 금액(1원 이상 검증), 첫 결제 여부 토글.
- **[영역 3] 결제 수단 4대 카테고리 구별 UI (그리드/카드형 배치)**:
  * 💳 카드사 수단 선택 (하나/신한/현대/KB 등)
  * 📱 통신사 혜택 선택 (T멤버십/KT/LGU+)
  * 💸 간편결제 선택 (네이버/카카오/토스/페이코)
  * 🎁 우회 결제 선택: "문화상품권 충전 및 해외 우회 결제 경로 포함하기" 체크박스/토글
- `validateForm` 검증 함수 및 [최저가 경로 계산하기] 제출 버튼 로직 설명.

### [4단계] 로딩 처리, 최저가 순위 카드 & 모달 팝업 UI (Result Step)
- `animate-spin` 원형 스피너 로딩 UI (1.5초 출력).
- 상위 3개 결제 경로 카드 리스트 (1위: amber 강조 테두리 + `ring-2` + 최저가 추천 배지).
  * 카드 내 구성: 순위/플랫폼, 정가 vs 실결제액, +적립 포인트, 즉시 적용 혜택 단계(`apply_steps`), 결제 팁(`guide_text`).
- [조건 재설정] 버튼 및 [환산 기준 보기] 클릭 시 "1P = 1원 환산 기준" 모달 팝업(`isModalOpen`) 렌더링.
- 최종적으로 1~4단계를 `src/App.tsx` 하나로 합쳤을 때의 구조 및 실행 안내 제공.
