## 페르소나 정의
당신은 시니어 프론트엔드 엔지니어이면서 UX/UI 설계 전문가이자 React + TypeScript 개발 전문가입니다.

## 문제 정의
- 모바일 게임('쿠키런: 킹덤') 인게임 재화 결제 시 파편화된 플랫폼(구글 플레이, 원스토어, 갤럭시 스토어, 앱스토어) 및 결제수단(네이버페이, 카카오페이, 토스페이, 통신사 멤버십, 카드사, 상품권 등)의 혜택을 통합 비교하여 실질 결제액 기준 최저가 경로를 추천하는 웹 프로토타입 UI/UX 개발.
- 1차 프로토타입 범위: 단일 게임('쿠키런: 킹덤') 한정, 비회원 기반 세션 메모리 처리, 4단계(입력→선택→계산 로딩→결과 목록) 단일 페이지 웹 애플리케이션(SPA) 구축.

## 프로그램 개발 환경
- 프레임워크: React (v18+) + TypeScript
- 빌드 도구: Vite (v5+)
- 스타일링: Tailwind CSS (v4)
- 아이콘: Lucide-react
- 브라우저 환경: Chrome, Safari 최신 버전 지원
- 코드 스타일 규격: ESLint, Prettier 및 Clean Code 원칙 준수

## 작업 절차
1. 프로젝트 기본 상태 및 데이터 구조 정의 (Types)
   - 게임/금액/보유수단 입력 상태 타입 정의
   - 계산 결과(순위, 최종가, 할인단계, 환산 포인트 등) 데이터 스키마 정의
2. 공통 UI 컴포넌트 구현
   - 상단 상시 안내 문구 배너 ("본 페이지는 검색 및 최저가 연산 기능 검증을 위한 프로토타입으로, 현재 [쿠키런: 킹덤] 1개 게임만 검색 가능합니다.")
   - 헤더 및 전체 다크모드/모던 레이아웃 래퍼
3. Step 01: 게임 검색 및 결제 금액 입력 폼 (Game & Amount Step)
   - '쿠키런: 킹덤' 키워드 유효성 검사 (오타/타 게임 입력 시 에러 팝업)
   - 결제 금액 정수(1원 이상) 입력 폼 및 예외 처리
4. Step 02: 보유 결제수단 자기신고 선택 폼 (Self-Report Step)
   - 간편결제(네이버/카카오/토스/페이코 등), 통신사(T/KT/LGU+), 카드사, 첫 결제 여부 선택 체크박스
   - 자기신고 주의사항 고지 문구 배치
5. Step 03: 최저가 연산 로딩 상태 및 더미 백엔드 연산 로직 (Calculation Engine Step)
   - 백엔드 API (Cloud Run POST /api/calculate) 구조를 모킹한 연산 함수 구현
   - 혜택 수수료, 최대한도(max_benefit_krw), 포인트 환산가치(1P=1원) 적용 최저가 정렬 로직
6. Step 04: 최저가 순위 결과 및 아웃링크 이동 화면 (Result Step)
   - 1위~5위 체감가 순위 카드 리스트 출력
   - 정가 vs 실결제액, 혜택 적용 단계(Steps), [환산 기준 보기] 팝업, [구매하기] 아웃링크 버튼
7. 전체 상태 통합 및 메인페이지 연동 (App.tsx)
   - Step 1 -> Step 2 -> Step 3 -> Step 4 로 자연스럽게 전환되는 단일 페이지 흐름 완성

## 요청 및 출력 규격

- 각 코드 블록에 대해 작성된 알고리즘의 동작 원리와 React Hook/TypeScript 문법을 초보자도 이해할 수 있도록 상세히 설명해 주세요.
